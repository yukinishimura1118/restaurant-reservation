# Restaurant Reservation

飲食店の予約サイトです。

## 概要

飲食店を検索して、希望する日時や人数で予約できるWebアプリケーションです。

## 機能

- 飲食店の一覧表示
- 飲食店の詳細表示
- 飲食店の予約
- 予約の確認
- 予約の変更
- 予約のキャンセル
- マイページ
- 管理者機能

## 使用技術

- Laravel 13
- MySQL
- Docker
- Laravel Sail
- Git / GitHub

## 開発環境

Laravel Sailを使用してDocker環境で開発しています。

#### Gitについて学んだこと

* `feature/mypage` は機能ごとに作る作業用ブランチ
* Pull Requestは、作業用ブランチの変更をmainへ取り込むための申請
* Mergeすると、作業用ブランチの変更がmainに取り込まれる
* Merge後は、不要になったfeatureブランチを削除できる
