# Restaurant Reservation

飲食店の予約サイトです。

## 概要

飲食店を検索して、希望する日時や人数で予約できるWebアプリケーションです。

## 機能

- 飲食店の一覧表示
- 飲食店の詳細表示
- 飲食店の予約
- 予約の確認
- 予約の変更
- 予約のキャンセル
- マイページ
- 管理者機能

## 使用技術

- Laravel 13
- MySQL
- Docker
- Laravel Sail
- Git / GitHub

## 開発環境

Laravel Sailを使用してDocker環境で開発しています。
